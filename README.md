# 베이블링 한자 출력기

**VAVELING 베이블링**(중국어 낱말 학습 앱)의 **모바일 도서검색기(JP1000) 전용 판**입니다.
프린터가 한 몸인 기기에서 중국어 낱말을 듣고, 획순을 보고, 바로 **종이로 뽑아 쓰면서** 익힙니다.

- 낱말 카드 — 한자 크게 · 병음 · 뜻 · 예문 · 쓰기 칸 · QR
- 쓰기 연습지 — 여러 낱말을 한 장에, 글자마다 쓰기 칸 1~3줄
- 단어 목록 — 한자 · 병음 · 뜻을 표로

이 저장소에는 **설치 파일(APK)만** 올립니다. 구글 플레이에 올릴 수 없는 기기(안드로이드 7.1 · 11)를 위한 배포 자리입니다.
폰·태블릿용 앱은 [Google Play](https://play.google.com/store/apps/details?id=com.vaveling.vaveling), 설치 없이 쓰려면 [vaveling.app](https://vaveling.app) 을 이용하세요.

## 처음 설치

1. 기기에서 **설정 → 보안 → 「알 수 없는 출처」 허용**을 켭니다.
2. [가장 새 판(Releases)](../../releases/latest) 에서 `vaveling-hanzi-printer-….apk` 를 받아 설치합니다.
3. 앱을 켜면 학습 자료(약 430MB)를 뒤에서 모두 받아 둡니다. 그 뒤로는 인터넷 없이도 듣고 뽑을 수 있습니다.

## 업데이트

앱이 켤 때마다 스스로 새 판을 확인합니다. 손으로 확인하려면
첫 화면 위쪽 🖨 → **한자 출력기 → 「새 판 확인」** 을 누르세요. 받은 뒤 설치 창에서 「설치」를 누르면 됩니다. 학습 기록은 그대로 남습니다.

## 대상 기기

- 모바일 도서검색기 JP1000 (A40i · 10.1인치 · 80mm 감열 프린터) — 안드로이드 7.1 / 11
- 프린터가 없는 기기에 깔면 학습은 되지만 인쇄는 되지 않습니다.
